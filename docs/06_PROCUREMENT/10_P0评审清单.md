## 已批准的 P0 决策基线

| 决策项 | 已批准结论 |
|---|---|
| 首个品类 | `IT.HARDWARE.LAPTOP` |
| 支持格式 | CSV、XLSX、文本型 PDF；P0 不支持 OCR、手写件和低质量扫描件 |
| 最少报价 | 标准案例 3 份；少于 3 份且无 `approved_exception_ref` 时返回 `insufficient_information` |
| 技术规格 | Mandatory Technical Specification 为 `blocker`，不能被 Weighted Score 抵消 |
| TCO | 使用已批准 Component；未知值不等于 0；金额保留 2 位小数并使用 `ROUND_HALF_UP` |
| Scoring | 采用 `05_制度与评分规范.md` 的 35/20/15/15/10/5 Weight 和 `2.0` Tie Tolerance |
| Supplier Match | High Confidence Threshold 为 `0.90`；低于阈值必须人工确认 |
| Source Freshness | Supplier/Restriction Snapshot 不超过 24 小时；FX 保留 Effective Date 和 Version |
| Restricted Supplier | P0 使用 Versioned Synthetic Fixture；触发后为 `blocker`，P0 不提供豁免 |
| Human Review | 单一 `business_reviewer`；申请人不得自批；P0 不支持 Delegation |
| Rejection | 驳回后创建关联的新 Workflow Instance，不复活旧 Workflow |
| Data Retention | Source/Derived File 90 天；Archived Decision Package/Audit 365 天；调试 Prompt 最多 30 天 |
| Real Data | P0 Phase A 禁止；只有实施 Gate 全部通过后才能接入 |

- [x] 产品定位是 Decision Support，不是 Autonomous Procurement。

- **P0 设计评审：附条件通过。**

Phase A 的实施顺序：

1. Finance Contract、Shared Metadata 和 Shared Core 第一批：已实现，待验收；
2. 按平台 Roadmap 实现 M1 Durable Agent Run；
3. 实现 M2 受控 Tool Runtime、Internal File Service Authentication 和 Approval Security；
4. 完成 Tenant Binding、Policy/Scoring Governance、Response Schema 和 Input Mapping；
5. 如 Phase B 需要外部数据，先完成对应 M3 Sandbox Connector；
6. 重新运行完整 Security/Contract/Runtime/Regression Review，再决定 Phase B 准入。

Phase B 或 Production Gate 不能因为本次设计评审而自动通过。每个未勾选项目必须由实现证据、测试结果和 Audit 记录关闭。
